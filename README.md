## 💎 Design & Visual Architecture (Monolithic Minimalist Glass)

The portfolio adheres strictly to a **70/30 Visual-to-Text ratio** — prioritizing live engineering telemetry, animated topologies, and interactive consoles over prose walls:

1. **Hardware-Accelerated Living Background (`MonolithicSpecularHorizon`)**:
   - 120 FPS GPU compositing via direct DOM ref transforms and requestAnimationFrame.
   - Zero React state re-renders on cursor movement (0ms input latency).
   - Continuous sinusoidal atmospheric breathing + idle harmonic Lissajous drift.
2. **Infinite Telemetry Conveyor Ribbon (`TelemetryMarquee`)**:
   - 60fps continuous horizontal telemetry ticker positioned directly beneath the Hero section.
   - Cycles official brand SVGs, live production data, and verified SLA metrics with pause-on-hover inspection.
3. **Floating Glass Capsule Navbar (`Navbar`)**:
   - Fixed-height frosted glass capsule with strict flex-shrink protection and 5 core desktop destinations.
   - Integrated quick CV link, theme toggle, and ⌘K quick jump palette.
4. **Hero Station (`HeroSectionV2`)**:
   - Cold specular horizon glow with 4 massive monolithic metric slabs (`80%+`, `75%`, `15k+`, `99.4%`).
   - Dual action CTAs and 1-click copyable email beacon.
5. **4-Stage Visual QA Pipeline (`PipelineSection`)**:
   - Interactive SVG topology graph mapping `PR Ingest` ➔ `Playwright Grid` ➔ `JMeter Concurrency` ➔ `Release Gate`.
6. **QA Audit Matrix (`QaMethodologySectionV2`)**:
   - Balanced 3×2 visual telemetry cockpit with bespoke interactive micro-diagrams across 6 core quality dimensions.
7. **Enterprise Experience Hub (`ExperienceSectionV2`)**:
   - Dual-column telemetry architecture displaying regression runtime cuts (`14h ➔ 3.5h`), concurrency SLAs (`15k VUs @ <1.74s p95`), and connected 5-node pipeline flows for **Shwapno** and **Paragon**.
8. **Featured Automation Architectures (`ProjectsSectionV2`)**:
   - Playwright TypeScript POM Suite, Apache JMeter 15k Stress Benchmark, and GitHub Actions CI/CD Quality Gate with live code consoles and SVG latency curves.
9. **Verified Credentials & Resume Station (`CertificationsSectionV2`, `ResumeSectionV2`)**:
   - Strictly verified honors (*nopStation Agility & Excellence Award*, *Batch 16 SQA Professional Certification*, *DIU B.Sc. in CSE*).
   - Instant PDF resume download serving `/resume.pdf`.
10. **Direct Communication Hub (`ContactSectionV2`)**:
    - One-click copyable communication channels (Email, WhatsApp/Phone, LinkedIn, GitHub, Dhaka status beacon). Zero unmaintained contact forms.

## 🚀 Getting Started Locally

### Prerequisites
- Node.js 18.18+ or 20+
- npm, pnpm, or bun

### Installation
```bash
# Clone the repository
git clone https://github.com/Shazzad01/myportfolio.git
cd myportfolio

# Install dependencies
npm install

# Start the local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the portfolio locally.

### Type Safety Verification
```bash
# Verify TypeScript integrity with zero build lock issues
npx tsc --noEmit
```
